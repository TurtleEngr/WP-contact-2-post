*** contact-2-post.php
- =cx2p_fErrorLog()= no longer calls =error_log()=. It only keeps the
  list in memory for that one submission.
- The 5 direct =error_log()= calls now use =cx2p_fErrorLog()= instead,
  so all 9 errors show in the popup.
- New =cx2p_fFeedbackResponse()=, hooked to CF7's
  =wpcf7_feedback_response= filter. It adds the list to CF7's reply to
  the browser as =cx2p_errors=. That filter runs after everything
  else, so every error has been collected by then.
- Removed the "Upload errors:" block in the post (=cx2p_fErrorBlock=,
  and the =$pErrorList= parameter), because it was saved in the
  database.

*** js/cx2p-paste.js
- New =cx2p_fShowErrors()= listens for CF7's =wpcf7submit= event and
  shows the alert.
- I put it in this file rather than a new one, because CF7 pages
  already load it. A new file would also mean changing the Makefile's
  zip file list and adding another script to load. The cost is that
  the name "paste" no longer quite fits; I updated the comment at the
  top.

*** README.org
- New "Error Popup" section: how it works, when the popup doesn't
  appear, and all 9 possible errors with what each one means.
- Updated the 3 places that mentioned =error_log=.
- Removed the "debug-log-manager" install step, since nothing is
  logged now, and renumbered the steps after it.

*** Things to know:
- **No popup on a PHP fatal error.** The form gets no reply at all, so
  there is nothing to show. That's the case where your form never
  returned, and this change doesn't fix it.
- **No popup without JavaScript.** If JavaScript is off in the
  browser, the errors are lost.
- **Visitors see server details.** As you chose, all errors are shown,
  so visitors also see setup errors. The "copy failed" and "not added
  to Media Library" messages include the full server path.
- **Not changed:** development.org still says =cx2p_fErrorLog()=
  writes to the PHP log. Want me to update it as well?
