*** How it converts:
- =<p>= becomes a Paragraph block.
- =<h1>=–=<h4>= become Heading blocks with the matching level.
- =<ul>= and =<ol>= become List blocks with List Item blocks. Nested
  lists stay nested.
- Loose text between those becomes its own paragraph.
- If the template paragraph has other text, such as =Details:
  {details} more=, it is split. "Details:" stays its own paragraph,
  then the new blocks follow, then "more".
- This works in paragraphs inside groups or columns too.
- A pasted value with only inline tags (=b=, =a=, =br= and so on)
  still stays inside the paragraph, since that was already valid.
- In a non-paragraph block, such as ={details}= in a heading, block
  tags can't go there. Only the inline tags are kept and the block
  tags become line breaks.
