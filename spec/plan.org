** Flamingo (free)
+ Home: https://contactform7.com/save-submitted-messages-with-flamingo/

+ https://contactform7.com/additional-settings/
+ https://contactform7.com/save-submitted-messages-with-flamingo/

+ Flamingo stores submitted messages directly in your website's
  WordPress database as custom post types.
+ Database Tables
  + wp_posts: Stores the core message data (using a custom post type
    for inbound messages).
  + wp_postmeta: Stores the message metadata, such as sender details,
    subject lines, and form fields. (Note: If you use a custom
    database prefix other than wp_, replace wp_ with your specific
    prefix).
